# Сільпо: картка товару — демо правил відображення

Демо картки товару для лістингу й каруселей: сітка 3 колонки і карусель зі сценаріями з брифу,
панель перемикачів для порівняння «Як є / Нові правила» і блок «Логіка відображення» поруч.

Чистий HTML/CSS/JS, без збірки.

## Онлайн

- Демо: https://gubish.github.io/silpo-plp-prototype/
- Код: https://github.com/gubish/silpo-plp-prototype (GitHub Pages з гілки `main`)
- Оновити онлайн-версію після правок: `git add -A && git commit -m "Що змінили" && git push`

## Як відкрити локально

```bash
python3 tools/serve.py
```

і відкрийте http://localhost:5174. Сервер без кешу: після правок достатньо оновити сторінку.

## Що де правити

| Хочу змінити…                          | Файл |
|----------------------------------------|------|
| Правила відображення картки            | `js/card.js` (і опис — `docs/card-rules.md`) |
| Вигляд картки                          | `css/card.css` |
| Товари демо, тексти, картинки          | `js/data.js` (`DATA.products`, `DATA.cardDemo`, `DATA.card`) |
| Панель перемикачів і текст «Логіка відображення» | `index.html`, `js/screens/card-demo.js`, `css/demo-card.css` |
| Кольори, шрифти, відступи              | `css/tokens.css` |
| Ціна, «+» / степер, «обране»           | `js/ui.js`, `css/components.css` |

## Правила

**Усі правила відображення й журнал рішень — [docs/card-rules.md](docs/card-rules.md).** Нове правило — спершу туди.

Бриф: `~/Desktop/silpo-card-brief.md`, Figma `8602:18153`.

Поля товару: `bb`, `bulk`, `markdown`, `installment`, `nutri`, `expected` (опис у `js/data.js`).
Розтермінування показується в усіх товарів від 1 000 ₴.

Панель: «Як є / Нові правила», знижка, попередня ціна, ББ, Nutri-Score, круглі бейджі,
debug-оверлей і підсвітка карток, де щось не влізло. «+» додає в кошик лише лічильник — екрана кошика немає.
