# Сільпо: прототип лістингу (PLP)

Базові екрани з прототипу ШІ-помічника (`Silpo AI/02`): головна, каталог, лістинг, картка товару.
Чат МГ, гілки дизайну, пошук, кошик і чекаут прибрані.

Чистий HTML/CSS/JS, без збірки.

## Онлайн

- Прототип: https://gubish.github.io/silpo-plp-prototype/
- Демо картки товару: https://gubish.github.io/silpo-plp-prototype/demo-card.html
- Код: https://github.com/gubish/silpo-plp-prototype (GitHub Pages з гілки `main`)
- Оновити онлайн-версію після правок: `git add -A && git commit -m "Що змінили" && git push`

## Як відкрити

```bash
python3 -m http.server 5174
```

http://localhost:5174. Екрани: `#home`, `#catalog`, `#listing/fruits`, `#pdp/banana`.
Демо картки товару: http://localhost:5174/demo-card.html

## Картка товару (лістинг і каруселі)

**Усі правила відображення й журнал рішень — [docs/card-rules.md](docs/card-rules.md).** Нове правило — спершу туди.

Бриф: `~/Desktop/silpo-card-brief.md`, Figma `8602:18153`. Під фото фіксований порядок:
ціна → бенефіти → інфо → вага → назва → Nutri-Score. Додаткових рядків (бенефіти, інфо) не більше двох,
зайві ховаються за пріоритетом `Card.PRIORITY`. Назва займає 2–4 рядки так, щоб низ карток у ряду збігався.

Нові поля товару: `bb`, `bulk`, `markdown`, `installment`, `nutri`, `tags`, `expected` (опис у `js/data.js`).
Nutri-Score стоїть окремим рядком одразу під назвою й не рахується в ліміт
(як у брифі, у слоті «Мета», — `Card.settings.nutriPlace = 'slot'`). Велнес-теги в лістингу не показуємо:
чипи на сторінці товару, у лістингу — фільтри.
На `demo-card.html` є панель: «Як є / Нові правила», режим ББ і знижки («На фото / В рядку»), Nutri-Score, debug-оверлей і підсвітка карток, де щось не влізло.

Кошик лишився тільки як лічильник: «+» перетворюється на степер, сума видно в таб-барі й на плашці,
але окремого екрана кошика немає, тож плашка й таб «Кошик» нікуди не ведуть.
